# 数据质量与结构评估 · 采集方向判定

> 2026-11-16｜`scripts/audit_data_quality.py` 全量跑数
> 体量：area 1093（active 1082）/ belt 118 / policy 1690 / source 464 / event 721 / region 3082

## 一、结论先行

**结构设计是对的，政策层质量过硬，但片区层有 18% 的实体证据链不达标，而采集方向已经过了拐点。**

三句话概括：

1. **该继续的不是「采」，是「审」**——198 个片区（18%）的名字唯一来源是媒体（央视、中新网、地方日报），违反项目自己定的证据制准入
2. **省级名单这条路只覆盖 14%**——153/1082 个片区有省级文件支撑，而省名单对账的几轮功夫只作用在这 14% 上
3. **「县骨干」在江西被证伪**——34 县里只有 6 个点名乡村片区（18%），九江批仅 6%

## 三、质量：三层差别很大

### 3.1 政策层：硬

- 1690 份全部有全文存档，`sha256` 逐条可核
- `instruments` 100%、`summary` 100%、`scope_desc` 99% 填充
- 抽取的 10,360,253 汉字

**但字段填充率存在硬约束**：

| 字段 | 填充率 | 意味着什么 |
|---|---|---|
| `doc_no` | **11%** | 九成政策无文号 → A/B 级区分主要靠栏目而非文号 |
| `budget_wan` | **13%** | 资金分析只能做片段，算不了投入密度 |
| `target_areas` | 33% | 覆盖规模分析受限 |
| `county_code` | 84% | 16% 无县级归属（省级综合文件） |

### 3.2 片区层：证据强度分层明显

按支撑文件层级统计（只看 `primary`+`support`，不含 mention）：

| 证据来源 | 片区数 | 占比 |
|---|---|---|
| 县级文件 | 454 | 42% |
| **无任何政策依据** | **246** | **23%** |
| 市级文件 | 189 | 17% |
| 省级文件 | **153** | **14%** |
| 镇级/其他 | 40 | 4% |

两个反直觉的点：

**第一，省级文件只支撑 14% 的片区。** 我们最近几轮全部精力都在「省级名单对账」，
但它能作用的上限就是这 14%。剩下 42% 靠县级文件、23% 无依据。

**第二，无依据那 246 个，名字来源有问题**（见第四节）。

## 四、最严重的问题：198 个片区的证据链只有媒体

对 246 个无政策依据的片区，追溯其 `first_source_id` 的域名：

| 来源性质 | 片区数 |
|---|---|
| 非 `.gov.cn`（媒体） | **198（80%）** |
| `.gov.cn`（可补政策层） | 45 |
| source 行缺失 | 3 |

样例：

```
A230001 甘南县长山乡—甘南镇(G301)精品示范带  ← 中新网黑龙江
A230003 饶河县乡村振兴示范区                ← 央视网乡村振兴频道
A220011 和龙市乡村振兴示范区                ← 央视网乡村振兴频道
A220006 九台区千村示范百村提升示范带（2条）    ← 长春发布/长春日报
```

按省分布：浙江 77、山东 39、江苏 19、四川 10、福建 8、广东 6……

**这违反 `CLAUDE.md` 决策日志 2025-06 定的原则**：

> 「片区」采用**证据制准入**（官方来源可核验）而非名称包含「片区」二字即可入库

而 `docs/07 §3.2` 明确「官方媒体（新华社、人民日报、省级党报）**仅入 source，不入 policy**」。
现在的问题是：媒体证据不仅进了 `source`，还成了 **198 个片区的唯一身份依据**。

补充一个全局数：1082 个片区里，`first_source` 指向非 `.gov.cn` 的有 **774 个（72%）**。
其中 576 个另有 `.gov.cn` 政策支撑（证据链成立），**只有 198 个是真短板**。

**这批的影响**：浙江 381 个片区里有 77 个属此类——这解释了为什么浙江覆盖率长期停在 87% 上不去。
不是没采，是这些名字本身可能就不是官方名。

## 五、三条路线的实测收益对比

| 路线 | 实测结果 | 判断 |
|---|---|---|
| **继续采政策** | 补链轮：2 小时 → 7 条政策 / 9 个片区 | 边际收益已接近零；剩余 167 个空心片区里约 10 个可采 |
| **省名单对账** | 4 省对平（辽宁/河北/湖北/河南 2025）；江苏、山东潍坊名单不公开 | 有效但天花板 14%；名单不公开的省无解 |
| **县骨干普查** | 江西 34 县：取到率 85%，点名率 **18%**（九江批 6%） | 低密度区证伪；高密度区（山东/浙江）未测 |
| **回头核（漏挂反查）** | 精确名匹配扩到全省：**新增 0** | 已挖尽 |

**结论：三种「往外采」的路子都在收益递减区间。**

## 六、方向判断：应当转入「提质」而非「扩量」

### 该做的三件事（按优先级）

**第一，198 个媒体来源片区做合法性审查。** 这是当前最大的质量风险，也是唯一能让统计口径站得住的动作。处置分三类：
- 能在 `.gov.cn` 找到官方名的 → 改名并补挂政策
- 找不到但确有其事的 → `status=待核`，统计时单列
- 查无实据的 → 移出 active（保留记录，`record_state=withdrawn`）

预计片区总数会从 1082 降到 900 上下，**但留下的都是可核验的**。

**第二，45 个「有 gov 来源但未入政策层」的片区补录。** 这些是纯增量且零风险：
source 表里已有 .gov.cn 原文，把它按政策层规范入库即可，覆盖率能涨约 4 个百分点。

**第三，字段口径固化成校验。** `town_codes` 三形态、`scale_villages` 混口径、`event` 覆盖率 41%
——这些不是采集问题，是**校验层没有硬约束**。新维度进来会重复同样命运。

### 不建议做的

- **不再按省派发补采**（已证伪）
- **暂不铺全国县骨干**（江西密度证明低密度区无增量，高密度区未测但风险已知）
- **暂不追覆盖率数字**——先把分子（片区身份）弄干净，再谈分母

### 如果要测高密度区

唯一还有信息价值的是测一个**已知高密度省**（山东沂水一个县就有 10 个片区名），
用来确定「县骨干」的上界。但这只回答「全国铺下去最多能有多少」，
不解决当前的数据质量问题。**建议放在合法性审查之后**。

## 七、一句话回答「方向是否正确」

**采集阶段的主线方向（证据制、全文存档、分层建库）是对的，执行质量也过硬；
但「继续扩大采集面」这个具体方向已经错了——现在 18% 的实体证据链不合格，
再往里加数据只会把问题放大。应当先停下扩量，把已有的 1082 个片区审干净。**
