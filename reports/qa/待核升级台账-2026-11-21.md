## 四、本轮新增的可复用契约

`upgrade_media_roster.py` 增 `--parent-key`：**同省多份名单必须按批次限定**，否则会把全省所有媒体名单一起升级
（实测不加限定会一次改动 SD 110 条待核，全部挂到同一政策上）。

```powershell
python scripts/ingest_policy.py data/stage/batches/POL-SD-rizhao2022-policy.jsonl
python scripts/upgrade_media_roster.py SD P370348 --parent-key 日照市市级美丽乡村片区2022
python scripts/merge_by_province.py; python scripts/build_db.py; python scripts/validate_db.py
python scripts/health_report.py; python scripts/check_doc_caliber.py --fix
```
