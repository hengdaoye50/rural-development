# 公众号采集通道（2026-11-21 实测）

## 结论
公众号是**当前最可能拿到县以下片区名单的渠道**，但只能做「发现 + 待核档案」，不能做政策层证据。

| 环节 | 工具 | 状态 | 说明 |
|---|---|---|---|
| 线索检索 | scripts/wechat_leads.py "省 片区 乡村振兴" | ✅ 可用 | 搜狗微信，一次 10 条，标题/摘要/日期可抓；已修 HTML 实体 |
| 正文抓取 | scripts/wechat_fetch.py | ❌ 受阻 | ①mp.weixin 直连返回「环境异常」验证码；②opencli Browser Bridge 未连接（需 Chrome 装 OpenCLI 扩展） |
| 名单抽取 | agent + write JSON | ✅ 可用 | 从摘要/snippet 抽片区名与县区，落 data/stage/candidates/ |
| 建档 | scripts/ingest_area_media_roster.py | ✅ 可用 | 写 area + source，status=待核，进 M 层、不进主统计 |
| 升级 | scripts/upgrade_media_roster.py | ✅ 可用 | 拿到 .gov.cn 原文后升 primary |

## 检索式（按此精检，泛「乡村振兴」相关度差）
- <省> 片区 名单、<市> 乡村振兴片区 公布、<县> 片区 认定
- <省> 乡村振兴片区 第X批、<省> 片区化 推进 乡村振兴
- 反向：<片区名> 片区 乡村振兴（确认官方表述）

## 正文抓取的解法（需用户一次操作）
Chrome 打开 chrome://extensions → 开发者模式 → 加载 OpenCLI 扩展（opencli 已装）→
opencli browser main open <url> 即可读正文。装上后我可以批量抓正文、抽名单、建 待核 档案。

## 与口径的关系
- 待核档案**计入 M 层总量**（用户 2026-11-21 裁定），但**不进主统计 629**
- 公众号**永不进 policy**（docs/07 白名单只收 .gov.cn），只能进 source
