# 政策层采集任务 · 分片 FJ01

## 你的任务

你是「全国乡村片区化数据库」政策采集团队成员。负责分片 **FJ01**（福建省），
共 **8 个县（区）**、**10 个已入库片区**。

本阶段是**探索性穷尽采集**：目标是尽可能完整地把这些县涉及片区化/乡村振兴片区建设的政策文本
带回来，**不设收录数量上限**。请把精力放在"多找、找准"上，不要为了凑格式而少收。

## 先读这些

1. `data/stage/shards/FJ01-counties.csv` —— 你要覆盖的县清单和各县已有 area_id
2. `docs/07-政策层.md` —— 权威门槛、检索入口、字段规则（**必读 §0、§2、§5**）

## 硬性边界

1. **只写一个文件**：`data/stage/batches/POL-FJ01-policy.jsonl`（UTF-8，每行一个 JSON）
   - ❌ 不写 `data/clean/`、❌ 不写 `data/db/`、❌ 不改任何 CSV
   - ❌ 不分配 `policy_id` / `event_id`（入库脚本串行编号）
2. **只收 `.gov.cn` 域名原文**或政府公报原件。聚合站（搜狐/新浪/腾讯/163/界面/52hrtt）、
   自媒体、公众号一律不收；新华社/人民日报等官方媒体只作线索
3. **必须给全文**：`full_text` 放正文 Markdown，不是摘要。这是唯一不可让步的要求
4. 只能引用 `FJ01-counties.csv` 里已有的 `area_id`，不得新建片区
5. `budget_wan` / `target_areas` 只填原文明确写出的数，**没有就留空，禁止估算**

## 收什么：能收多少收多少

同一个县的相关文件不嫌多。**不要找到一份就收手**，也不要因为"已经有同类了就跳过"。

| 类别 | 尽量都收 |
|---|---|
| 名单 / 批复 / 公告 | 每一批次都收，不只收最新的 |
| 规划 | 片区专项规划、国土空间规划涉农部分、村庄布局规划、"十五五"涉农规划 |
| 组织 | 领导小组、专班、联合党委、片区党委的成立与调整文件 |
| 资金 | 专项资金管理办法、资金下达通知、奖补办法 |
| 考核 | 考核办法、评分细则、验收标准、通报 |
| 政务动态 | 推进会、观摩、调研、挂牌、签约、评估结果、入选消息 |
| 关联文本 | 招标采购公告、人大建议与政协提案答复、巡察审计反馈涉片区部分 |
| 多级链条 | 省级 → 市级 → 县级 → 乡镇，各层级都收 |

**唯一下限**：尽量找到每个已入库片区的**设立依据**（`area` 是怎么来的）。

## 检索路径

1. 县政府门户 → 政务公开（`/zwgk/`、`/zfxxgk/`、`/xxgk/`、`/gongkai/`、`/gkmlpt/`、`/OpennessContent/`）→ 政策文件
2. 县农业农村局子站 → 通知公告
3. 市农业农村局 / 市政府 → 政策文件（`/zcwj/`、`/zcfg/`、`/zfwj/`）
4. 政府公报（`/zfgb/`）
5. 省级：省农业农村厅政务公开、省政府政策文件库、省委农办
6. 特殊入口：公共资源交易中心（片区规划编制成交公告）、人大建议答复（`/jytabl/`）、
   财政局专项资金下达通知、发改委规划栏目

**市级/省级政府站的"政策文件库"常收录下辖区县文件**，区县自建站检索不到时优先试这条路。

## 字段说明（要点）

- `instruments`：**描述性标签，不是分类变量**。九类（财政 土地 组织 考核 规划 人才 金融 产业 数字）
  只是常用词表，**地方特有提法照原文记入**（如「片区组团」「强村公司」「两进两回」「百千工程」）。
  **不设数量上限，有表述就记，不确定时倾向记下。** 纯名单/纯批复可留空。
- `issuer_level`：`province` / `city` / `county` / `town` / `other`（省政府办公厅转发市文件 → `province`）
- `issued_ymd` = 文末落款的成文日期；`published_ymd` = 政府网公开日期，两者常差数周
- `doc_type`：`意见 方案 规划 通知 办法 批复 决定 导则 名单 公告 动态 答复 指南 总结 报告 其他`
  （**人大建议/政协提案的复函与答复一律记 `答复`**，这是县级信息量最大的一类文件；
  工作总结/政府工作报告记 `总结`/`报告`；项目库入库指南记 `指南`）
- `source_kind`：`政策文件` / `政府公报` / `部门动态` / `新闻发布`
- `credibility`：`A`（正式文件）/ `B`（部门动态，无文号）
- `rel`：`primary`（直接设立/批复/命名该片区）/ `support`（点名支持）/ `mention`（仅提及）
- 若某文件确实不点名任何片区（如省级普适文件），`areas` 给空数组即可

## 完成时报告

用 300 字以内说明：**收了多少条、覆盖哪些县、每个县各收了几条**、
哪些县确实检索不到（要写清试过哪些入口）、以及本地的政策话语特点
（比如当地方言化的提法、片区怎么命名、是市级命名还是县级自主）。

找不到就如实说「该县未检索到公开政策文件」，**绝不编造**文号、金额、片区数。
