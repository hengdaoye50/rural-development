## 附：衢江区“县城—中心镇—重点村”发展轴空间专项规划（2025—2035年）（草案）主要内容

### 1 发展轴总体架构：“城镇村”发展轴体系

总体结构：“12210”发展轴——“一城两镇、两轴十片区”

- 一城：即衢江城区
- 两镇：即廿里镇、高家镇两个中心镇
- 两轴：即衢江廿里产城融合发展轴、衢江高家产城融合发展轴
- 十片区：即十个重点村组团片区：泉井边村“酒稻蔗礼”片区、盈川村“诗画古韵”片区、上宇村“青年乐享”片区、希望新村“菌乡匠域”片区、马蹊村“下自成蹊”片区、贺邵溪村“初心向阳”片区、东岳村“大美之洲”片区、白水村“泽畔耕旅·杜泽新贸集”片区、湖南村“小湖鲜”片区、外黄村“薯链万家”片区。

n “一城”：做强衢江城区作为重点，打造县域经济的核心引擎；
n “两镇”：打造廿里、高家2个省级中心镇，形成发展轴的桥梁纽带；
n “两轴”：分别为衢江廿里产城融合发展轴，重点是发展新材料智造产业、高效设施农业；衢江高家产城融合发展轴，重点是发展临空临港产业、乡村农文旅产业；
n “十片区”：建设10个重点村片区组团，实现连片发展。

### 2 发展轴范围

县城、中心镇、其他乡镇、重点村、片区组团的构成，涉及中心城区、廿里镇、杜泽镇、莲花镇、后溪镇、全旺镇、湖南镇、大洲镇、云溪乡等。

|---|---|---|

n 发展轴空间：涉及8镇1乡3街道1办事处，总面积568.71平方公里，占32.53%。
n 发展轴内人口：发展轴范围内现状总人口约27.21万人，占全区常住总人口72.76%。其中城区12.19万人，中心镇8.10万人，重点村组团6.92万人（不包含城区和中心镇内组团片区）。

### 3.1 战略定位与产业空间布局

中产城、南配套、北港城，协同两翼文旅。

n 工业平台：以空港新城、多式联运枢纽港等平台、廿里镇特色生态产业平台、创新型产业（M0）平台、青年创业就业中心、数字经济产业园、微短剧基地等做强产业集群效应。
n 文旅平台：发挥姑蔑古国考古遗址、盈川千年古城、皇朝墩考古遗址、药王山风景区、天脊龙门山景区等优质文旅资源，助推文化旅游高质量发展。
n 农业平台：打造后溪工厂化循环水养殖、高家未来农业园区、浙西中草药种业种苗科研繁育基地等特色现代农业项目，推动农业新质生产力发展。
