| | | | | | 22日下午，市委书记黄胜可来到佐村镇，深入村庄调研集体经济发展和基层治理工作。他强调，要全面落实省委以“千万工程”牵引缩小“三大差距”、推进共同富裕先行示范的工作部署，统筹做好“强城”“兴村”“融合”三篇文章，建强“县城—中心镇—重点村”发展轴，推进城乡一体融合发展，以奋进姿态描绘共同富裕新图景。
在山合村，黄胜可实地查看村庄环境，边走边了解集体经济发展、基层党组织建设、后备力量培育等情况。山合村依托千亩玄武岩梯田，积极引进红藜麦种植产业，计划打造集特色种植、加工与文旅体验于一体的全产业链基地。该项目的引进，可以增加集体经济经营性收入，同时带动村民家门口就业。黄胜可在详细了解项目进展后，叮嘱镇村干部要立足资源禀赋，积极推动农文旅深度融合，促进集体增收村民致富。
来到斯光村，黄胜可与村干部深入交流，并驻足“三务”公开栏前，详细了解村务议事决策程序、创业承诺落实、村干部值班等情况。斯光村坚持党建引领，每月开展党员干部义务劳动，同时严格落实村干部坐岗值班制度，及时为群众排忧解难。黄胜可指出，要认真落实好村干部坐岗值班等制度，既方便服务群众，也有利于第一时间排查化解矛盾纠纷。他同时勉励村干部巩固集体经济发展成果，进一步做大做强村集体经济。
前塘村位于海拔350米的生态高地，村内有古树群和影视外景拍摄基地。今年，村里将废弃的砖瓦厂改建为露营基地，并举办了乡村共富市集，实现经济效益和社会效益“双赢”。黄胜可实地察看了红泥湾露营基地，对村庄通过盘活闲置资产拓宽集体增收渠道给予肯定，要求镇村干部以安全筑基，发挥资源优势，因地制宜发展乡村游等业态，有力助推乡村振兴。他同时指出，村干部要听民声、集民意，团结实干，以实实在在的成绩赢得群众口碑。
在汇报会上，佐村镇负责人汇报了重点工作进展情况，与会部门单位负责人作交流发言。
黄胜可指出，佐村镇今年以来经济社会运行平稳有序，基层治理成效明显，值得肯定。就做好下步工作，黄胜可强调，佐村镇作为生态型乡镇，要按照年初既定目标任务，全力以赴、一抓到底，为推动东阳高质量发展突破突围作出贡献。发展是根本，要积极招引优质项目，做好“东阳人经济回归”，大力推动农文旅融合，推进乡村片区化、组团式发展。稳定是前提，要久久为功提升基层治理效能，抓好初信初访和积案化解，彻底改变信访工作生态。干部是关键，要坚持党建引领，选优配强“领头羊”，加强村干部队伍建设，进一步提升基层治理水平。作风是保障，要扎实开展深入贯彻中央八项规定精神学习教育，加强纪律作风建设，一级带一级转作风、树新风，为高质量发展提供坚强保障。
