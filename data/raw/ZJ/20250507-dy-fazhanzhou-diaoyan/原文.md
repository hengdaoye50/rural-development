| | | | | | 记者 胡剑文 摄影 包康轩
5月6日下午，市委书记黄胜可调研“县城-中心镇-重点村”发展轴建设工作。他强调，要深入学习贯彻习近平总书记重要讲话重要指示精神，聚焦“一个首要任务、三个主攻方向、两个根本”，一体做好“强城”“兴村”“融合”三篇文章，扎实推进发展轴建设，打造具有东阳辨识度的共富标志性成果。
市领导胡利群、王松明、蒋国威参加调研。
我市横店“影视+”发展轴以县城为起点，经横店镇、南马镇2个中心镇，带动城东街道、六石街道、南市街道、湖溪镇、东阳江镇、佐村镇、三单乡等7个协同镇街，近期围绕寀卢村、官桥村、花园村、八里湾村、紫阳村、前塘村、三单村等7个重点村开展7个片区组团建设，同期培育主轴外6个片区组团，整体构建形成“1+2+13”的发展轴结构体系。
黄胜可在城东街道寀卢村调研
黄胜可先后来到城东街道寀卢村、六石街道后里村和蟠松村，实地察看田园驿站综合体、木雕青创硅谷和宠悦动感乐园等项目。每到一地，黄胜可详细了解项目谋划、业态招引、“五一”假期客流等情况。寀卢村作为发展轴重点村之一，依托共享田园景观，打造共享式田园驿站综合体，推动田园资源向共富动能转化。木雕青创硅谷建设项目依托木雕非遗技艺与广厦大学教育资源，打造青年创新创业生态圈。宠悦动感乐园建设项目主要改造砖瓦厂旧址，打造多元场景融合的微度假体系。黄胜可指出，要不断深化新时代“寀卢经验”，整合片区内共享田园、木雕小镇、广厦大学等资源，着眼长远、充分论证，精心谋划项目，打造以农文旅融合、木雕技艺创新、校地合作赋能青创孵化为特色亮点的共富片区组团。
黄胜可在横店镇官桥村调研
横店镇官桥片区充分发挥横店影视城景区核心带动和影视文化产业资源优势，以“影视+”赋能村庄产业发展和村集体增收。黄胜可走进官桥村，参观了老街和“八间头”等古建筑，并与村干部、商户亲切交流，详细了解风貌提升、业态培育等情况，对村庄依托古建筑资源吸引众多影视剧组前来拍摄表示肯定。在中兴联村玖点片场，数个剧组正在拍摄微短剧。黄胜可参观了片场，详细了解剧组拍摄情况，勉励片场负责人利用横店丰富的拍摄资源，扎根横店再创新业绩。来到富贤塘村，黄胜可实地察看了外景文旅拍摄基地建设项目。他指出，要积极谋划项目，主动承接横店影视文化产业溢出效应，促进集体增收，带动村民致富。
黄胜可在调研中强调，发展轴是县域城乡融合发展的主要通道、缩小“三大差距”的重要载体，各镇乡街道和相关部门要精心谋划推进项目，积极争取政策要素支持，做好业态规划培育，加快特色产业发展，建强发展轴。要推广组团联建发展模式，分批谋划推进一批具有示范意义和辐射效应的重点村，带动地缘相近、资源相似、产业互补的周边村实现一体化发展。
