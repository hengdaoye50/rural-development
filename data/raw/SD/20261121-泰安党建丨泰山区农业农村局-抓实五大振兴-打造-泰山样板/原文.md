# 泰安党建丨泰山区农业农村局：抓实五大振兴 打造“泰山样板”

TATV泰安党建

_2020年6月17日 17:14_

泰山区农业农村工作以“乡村振兴战略”为统揽，坚持以“五大振兴”为指引，围绕“建设农业特区、打造精品农业”目标，打造乡村振兴“泰山样板”，实施两高园区引领、乡村振兴双轮驱动，大力发展特色精品农业，实施品牌战略，推进农业供给侧结构性改革，努力构建现代农业产业体系、生产体系、经营体系，实现农村一二三产业深度融合发展。

 初夏时节，走进泰山东麓的泰山区国家现代农业产业园区，只见省庄镇小津口村北端的山坡梯田上，茶树郁郁葱葱，装点着田埂；茶农们正在辛勤劳作，趁着好时光把最嫩的茶叶采摘下来，准备后续的摊晾、炒制。葱茏的茶树，连片的茶园，奏响了泰山区乡村振兴产业发展的美妙音符，展现出泰山区实施两高园区引领、乡村振兴驱动的美好画卷。

**泰山区农业农村局党组成员**

**主任科员 米静**

泰山区国家现代农业产业园重点突出两大主导产业，泰山茶和生态奶业，我们重点启动建设了9个重点项目，对泰山茶产业基地进行了扩规提档。目前泰山茶产值达到25亿元，生态奶业产值达到10亿元，其中我们的泰山茶作为主导产业，是重点支持建设的投资项目，基地扩面达到1万亩，累计达到3.5万亩，为园区建设注入了生命力，园区总产值达到35亿元，极大的带动了园区内42个村的产业振兴。

泰山区是市中区，农业主要分布在泰城东部和北部山区，地少人多，现实条件要求泰山区现代农业发展必须立足特色，做成精品，实现高效。结合这一实际情况，泰山区农业农村局着力推进园区创建，聚焦农业特区打造，实施两高园区引领、乡村振兴双轮驱动，通过项目带动，市场化运作，形成集聚效应，让特色农业产业成为农民增收、乡村振兴的新支点。

' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E>)

**泰山区农业农村局局长**

**乡村振兴领导小组办公室主任 张允峰**

2019年，泰山区乡村振兴工作以示范创建为引领，以项目建设为抓手，强力推进产业振兴、人才振兴、文化振兴、生态振兴、组织振兴“五大振兴”，在全市乡村振兴年终考核中取得第二名，泰山区国家现代农业产业园以全国第二名的好成绩通过国家认定，获得中央奖补资金1亿元。

' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E>)

' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E>)

随着乡村振兴的全面铺开，泰山区高位定制，确定3个示范区、14个示范村、29个创建项目，构建一村一品、一村一韵的和美景观，形成重点示范、梯次开花、竞相发展的乡村振兴生动局面。突出项目和品牌建设，助力乡村振兴，不断壮大泰山茶、花卉苗木、生态奶业、有机蔬菜、乡村旅游五大特色产业。实施与鲁商集团合作的齐鲁样板泰山人家、与银光集团合作的泰山茶旅小镇等项目28个。举办泰山苗木花卉交易会、泰山茶博览会，打响“国山圣水·茶礼天下”等品牌。培植农业休闲点100个，助推泰山一日游变为吃住休闲游，旅游收入达3.5亿元。同时提升国家农业科技园，投资1.9亿元建设现代农业科技孵化器项目，建成集大数据服务、技术研发、成果转化等功能于一体的创新创业中心，引领未来农业。成为全省唯一具有两个“国字号”农业园的县市区。

在乡村振兴的大潮中，泰山区依靠产业振兴，推动特色精品农业发展，而最直接的就是农民致富增收。省庄镇安家庄村借助乡村振兴的大潮，利用山林优势，大力发展林果经济，现已形成大片采摘园。山上林果飘香，山下安居乐业，乡村旅游经济也随着10栋民宿的建成发展逐步形成。

**泰山区省庄镇安庄村 党支部书记 吴曰胜**

安庄村自乡村振兴以来，引进了咱们泰安市的颐养项目，投资近10个亿，直接安排我们村的就业人员近500口人。这个村发展苗木为主体，我们的乡村旅游有150亩地杏林采摘，50亩地的猕猴桃采摘，50亩地的樱桃采摘，今年预计农民收入近2万元，村里增收近百万元。下一步通过这些项目的发展，我们这个村和农民每年增收利润10%。

' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E>)

现在的泰山区，项目多了，村庄美了，游客多了，村民笑了，园区建设有条不紊，美丽乡村覆盖率达到87%，活动场所全覆盖，一幅全面乡村振兴的美好画卷正徐徐展开。

' fill='%23FFFFFF'%3E%3Crect x='249' y='126' width='1' height='1'%3E%3C/rect%3E%3C/g%3E%3C/g%3E%3C/svg%3E>)

**泰山区农业农村局局长**

**乡村振兴领导小组办公室主任 张允峰**

2020年，我们的总体目标是，乡村振兴工作继续位于全市前列，争列全省“齐鲁样板”第一方阵。重点做好五项工作：加强组织领导，成立以区委书记、区长为双组长的全区乡村振兴领导小组。做好示范创建，今年集中力量，重点建设北部山区、花样年华等全区乡村振兴三大片区，积极打造王林坡市级乡村振兴先行区，努力争创邱家店省级乡村振兴示范区。做好国家现代农业产业园建设。做好双招双引工作，实施三个一批工程，投资26亿元建设完成23个农业重点项目，建设农业特区，统筹推进五大振兴，建设和美泰山乡村，努力打造泰山区乡村振兴泰山样板。
