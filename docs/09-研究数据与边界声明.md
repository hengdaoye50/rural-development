> 用途：论文/报告「数据与方法」一节可直接引用的口径声明。

## 一、研究中该用哪个总数（结论）

**主分析样本 N = 570。**（2026-11-18 三：P4 裁定 + T2 名单补采后；此前 470、468、446）

理由：一条记录要进主分析，必须同时满足**可归时**与**可归因**两个条件——

- 可归时：成立时间落在 2022-01-01 至 2066-12-31，或虽早于此但在 2023-01-01 之后仍有
  `primary`/`support` 政策或事件（判为延续至今）；
- 可归因：政策正文**点名**该片区，并作为设立/命名依据（`primary`）或点名支持（`support`）。

两者缺一，该记录就无法进入任何「按年份」「按政策」的交叉分析，因此不进 N。

**辅助样本与分层**（论文中作为稳健性检验与附录）：

| 层 | 数量 | 定义 | 在论文中的位置 |
|---|---|---|---|
| **主分析样本** | **570** | 可归时 + 可归因 | 正文全部描述统计与回归 |
| 含时间不详 | **774** | 有依据但成立时间不可考（204 条） | 稳健性检验：放宽时间要求后结论是否稳定 |
| 命名单元（宏观层） | 1 222 | `area` + `belt` 去跨表重名的命名单元 | 附录/脚注，仅用于说明采集规模与地域分布 |
| 待核 | 556 | 证据链或实体认定不达标：唯一来源为媒体稿（172 条）、名称/规模待核、无具名实体等 | 附录，不计入任何分子 |
| 无依据 | 12 | 无 `primary`/`support`，正文只提地名 | 附录，作为「被称作片区的单元」清单 |

### 1.1 「片区数」到底该取哪个：一张分解表

容易混淆的是宏观层的 **1 222**——它**不是片区总数**，而是「命名单元」总数：

| 构成 | 数量 | 是不是「片区」 |
|---|---|---|
| `area` 实体片区（在册 active，含待核） | 1 122 | 是 |
| `belt` 象征单元（示范带/圈/廊，去跨表重名后） | 100 | **不是**，按 `docs/01` §11 单列 |
| 合计 = 宏观层命名单元 | **1 222** | — |

再往里收一层（全是 `area`）：

```
1 347  在册实体片区（active，含 556 条待核）
  791  非待核
  774  有 primary/support 依据（宽统计，含 187 条时间不详）
  570  可归时 + 可归因（主分析样本）
```

**论文写「片区数量」时必须写清是哪一层**，并记住 1 353 里含 100 个象征单元、351 条待核。

### 1.2 县覆盖率的分子分母

宏观层报的 **595/2 856 = 20.8%** 指「**有命名单元的县 / 全部县级单位**」：

- 分子 534：有 `area` 记录的县（含仅因待核记录才计入的县）；`belt` 未额外增加任何县
  （只靠 belt 才进入统计的县 = 0）
- 分母 2 856：`region` 表中全部县级单位，**其中 979 个是市辖区**
- 若只算「片区内非待核」口径，是 **364/2 856 = 12.7%**

两个都合法，但语义不同：22.3% 是「**见到过这个名字的县**」，17.1% 是「**有可信记录在册的县**」。
论文里建议报 17.1% 并注明另一口径，或直接报 487 个县这个绝对数、避免比例歧义。

### 1.3 案例池：能写成案例的有多少

`主统计 570` 只保证「可归时 + 有依据」，写案例还需要**内容**。按四要素取三入池：

| 要素 | 判据（都可回原文核） | 471 中达标 |
|---|---|---|
| 覆盖可述 | `cover_desc` ≥20 字且不等于名称 | 233 |
| 规模可知 | 有 `scale_villages` 或 `scale_towns` | — |
| 有事件 | 至少 1 条 `event`（设立/入选/批复等） | — |
| 时间可精到月 | `founded_precision` 为 `day`/`month` | — |

| 档 | 判据 | 数量 | 建议用途 |
|---|---|---|---|
| **A 案例池** | 四要素中满足 **≥3** | **236** | 正文案例分析与类型学 |
| B 简案 | 满足 2 | 255 | 脚注、附表中的补充例证 |
| C 仅附表 | 满足 ≤1 | 91 | 只出现在名录里 |
| D 时间不详或口径外 | — | 327 | 不进任何分析 |
| E 无依据 | — | 12 | 附录清单 |

**A 档 236 的结构必须先看，再决定怎么用**：

- 地域：浙江 112（占 47%）、山东 25、江苏 23、辽宁 18，其余各省多为个位数
- 设立方式：`deployment` 171 / `roster` 65 —— **案例池以部署型为主**，
  即多数没有单独的设立文件，写「设立方式」时必须分列，不能笼统说「有官方文件」
- 四要素达标数：覆盖有效 169、有规模 171、有 event 195、日期到月 214
  （因取三即入池，各项合计不等于 236）

若要更严的子集：

| 串联口径 | 数量 | 适用 |
|---|---|---|
| 覆盖 + 规模 | 104 | 中等样本案例研究（能做规模比较） |
| 覆盖 + 规模 + 事件 | 63 | 可讲清「怎么设的」 |
| 四要素全备 | 41 | 完整深描（可写单案例长文） |

清单：`reports/qa/case-pool.csv`（含每条的四要素标记与满足数），`scripts/case_pool.py` 可重跑。

**不要写「全国共有 X 个片区」。** 本文的 570 是**证据可核验且时点可归的单元数**，
不是全国片区总量；后者在互联网上不可获得（见 §五）。

## 二、数据来源

| 项 | 内容 |
|---|---|
| 来源类型 | 仅中国大陆 `.gov.cn` 域名的政府网站与政府公报（白名单制） |
| 覆盖 | 31 个省级单位，含省、市、县三级发文机关 |
| 规模 | **1 702 份政策全文，合计 1 038.3 万汉字**；其中 A 级（政策文件/政府公报）496 份 |
| 存档 | 全文以 UTF-8 落盘于 `data/raw/{省码}/{日期}-{slug}/原文.md`，逐条记录 `sha256`，可校验 |
| 来源层级 | 县级 1 137 份、市级 277 份、镇级 165 份、省级 120 份、其他 3 份（按发文机关统计） |
| 辅助来源 | 权威媒体与政务公众号**仅用于发现线索**，不构成政策依据（不得进政策层） |

采集方式：按「县 × 政策链条」为单位检索，入口包括省/市/县官网站内检索、政府公报栏目、
人大建议与政协提案答复、财政专项资金公示、招投标公告；县级政府工作报告与「十五五」规划
是覆盖率最高的两类文本。检索通道清单与各站可用性见 `reports/gaps/coverage-gaps.md`。

## 四、分析层次怎么定

三层，各有自己的分母，**不共用、不相减**：

1. **宏观层（看多少）**——命名单元 1 353 个，覆盖 637 个县（县级单位共 2 856 个，22.3%）。
   只用于回答「量级与地域分布」，**不作因果分析的分母**。
2. **政策层（看机制）**——主样本 471 个，每个都有可读的政策全文支撑。
   论文中关于「以何种方式设立、依托何种政策工具、由哪级政府推动」的分析全部在此层。
3. **时间序列层**——471 中可归日的子集，用于趋势描述；187 条时间不详者一律排除在年份图之外。

对应的可视化与表格：省级分布必须同时给「绝对数」与「县覆盖率」，因为后者才反映采集完整性。

## 五、数据边界：三类不可得，必须写进局限

| 不可得 | 具体表现 | 处理方式 |
|---|---|---|
| **全国/全省总量不可得** | 多数省不公开逐条名单。山东官方口径「省市县累计 2 070 个」是三级累计投入计数，含「提升」（对既有片区再投入）与跨层重复命名，与本文「命名事件 + 证据」单位不可通约 | 不设官方数为分母；官方数与库内数只在同一层级、同一口径下并列，标明不可相除（见 `reports/qa/provincial-targets.md`） |
| **重复建设与撤销不可测** | 提升、更名、撤销多不单独发文；库内 1 122 条 active 片区中仅 455 条有生命周期事件记录，无一条「撤销」 | 记录单位为「命名事件」而非「实体一生」，从而不需解决该问题；已在局限中声明 |
| **检索通道覆盖不均** | 部分省级站检索失效、县级站 JS 渲染或反爬；`reports/gaps/coverage-gaps.md` 记录了各站可用性 | 按「可获得性」分档报数（A 可对账 / B 只建档 / C 案例层 / D 未采到），档内可比、跨档不可比 |

**写作建议**：在方法节明确写出「本研究不是全国普查，而是以证据可得性为边界的建档式抽样；
其价值在于每条记录可回查原文，而非数量逼近官方统计」。

## 六、可用性声明（能回答 / 不能回答）

**能**：
- 各省片区化推进的**制度形态**（载体名称、设立方式、依托政策工具、牵头部门）
- 同一县内多个单元的**空间与规模信息**（村数、镇数、面积，有原文出处者）
- 政策文本的**话语与工具差异**（全库中「片区组团」出现 467 次、「跨村联建」45 次、
  「强村公司」114 次，各省分布差异明显）
- 东部沿海与中西部的**类型差异**（在 A/B 档省内可比较）

**不能**：
- 「全国有多少个片区」或任何以官方累计数为分母的覆盖率
- 省际总量排名（采集深度差异大于实质差异）
- 片区设立对经济绩效的因果效应（无面板、无匹配、采集非随机）
- 片区内部治理绩效的跨省比较（村级数据缺失，`area_region_map` 的 village 级记录尚未建立）
