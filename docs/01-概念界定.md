# 01 · 概念界定

> 版本：v0.1 草案｜权威约束见 `../CLAUDE.md`｜未裁定案例写入文末「待裁定」

## 1. 核心术语

| 术语 | 本项目含义 |
|---|---|
| **片区** | 在县/区（含县级市、旗、特区）**以下**，为推进乡村振兴而**实体化设立**的连片治理或发展单元 |
| **实体化设立** | 有发文、挂牌、成立组织（联合党委/党工委/指挥部/专班）、或列入市县正式实施方案的清单 |
| **覆盖范围** | 片区明确或可合理推定的乡镇/村名单；不可推定则只填所属县 |
| **来源** | 可打开或已存档的官方/权威文本，含 URL、标题、发布者、日期、原文摘录 |

## 2. 纳入标准（四条同时满足）

1. **层级**：设立主体或覆盖空间在**县/区以下**  
   - ✔ 跨村联片、多村联合、乡镇级组团、村企片区、一乡镇内多村  
   - ✘ 全县域「示范县」、市域「示范带」（无县域以下实体单元）
2. **目的**：文本明确服务乡村振兴（产业/人才/文化/生态/组织）或和美/美丽乡村建设
3. **制度**：存在设立动作（§核心术语「实体化设立」）
4. **证据**：≥1 条符合 §5 的来源

## 3. 排除标准（满足任一即排除）

| 编号 | 排除情形 | 示例 |
|---|---|---|
| E01 | 纯行政区划单位 | 某镇、某街道、某行政村 |
| E02 | 县级及以上创建活动 | 乡村振兴示范县、农业现代化示范县 |
| E03 | 仅有规划口号，无设立动作 | 「要打造 XX 片区」但无发文/挂牌/组织 |
| E04 | 纯产业园区/景区/房地产，无乡村振兴任务 | XX 工业园、XX 风景区 |
| E05 | 临时项目部、活动周、一次性观摩点 | 赛事分会场 |
| E06 | 无任何官方/权威旁证的自媒体爆料 | 营销号截屏 |
| E07 | 省级及以上片区（跨市连片）无县域以下执行单元 | 某省「乡村振兴示范带」横跨三市且无县级以下片区 |

**E07 / 象征性命名例外**：满足「公开命名 + 振兴语义」但**无实体设立动作**的示范带/圈/廊/片，**不入 `area`，改入 `belt` 表**（见数据字典 §10）。有指挥部/联合党委/分村名单者仍入 `area` T03。

## 4. 类型学 v0.1

入库时 `type_code` 必须属于下表；新类型先改本表再入库。

| code | 名称 | 判定要点 | 优先认 |
|---|---|---|---|
| T01 | 示范片区 | 名称或文件直接称「乡村振兴示范片区」「和美乡村示范片区」等 | 名称含「示范片区」 |
| T02 | 片区联合党委 | 有片区级党组织/党工委/党建共同体实体 | 组织设立文件 |
| T03 | 示范带/廊/圈 | 带状/环状连片 + 有片区化推进机制（指挥部/规划/名单） | 机制证据 > 名称 |
| T04 | 产业片区 | 现代农业/特色产业连片，带乡村振兴任务书 | 任务书/实施方案 |
| T05 | 农文旅片区 | 乡村旅游重点村连片、休闲农业集聚 | 文旅+农业双部门文件优先 |
| T06 | 帮扶协作片区 | 重点帮扶、易地搬迁后续、东西部协作县域子片区 | 帮扶协作方案 |
| T07 | 城乡融合片区 | 城郊连片、城乡融合试验区的县以下单元 | 试验区子单元名单 |
| T08 | 改革试验片区 | 宅基地、集体经营性产权等改革的连片试点 | 改革方案清单 |

**并列**：一单元可主归一类，多标签记入 `tags`（数据字典），不造复合 code。

## 5. 证据标准

| cred | 级别 | 说明 | 能否单独入库 |
|---|---|---|---|
| A | 官方原文 | 政府网、部委、党建网，含文号或规范标题 | 能 |
| B | 官方报道 | 官方媒体/部门公众号，有发布日期 | 能 |
| C | 权威媒体 | 人民日报、新华社、省级党报 | 能，建议补 A/B |
| D | 学术/第三方调研 | 期刊、智库报告 | 否，须与 A/B/C 并用 |
| E | 线索 | 会议纪要、口头、未存档页面 | 否，只进 `status=待核` |

## 6. 边界案例裁定

| 编号 | 情形 | 裁定 | 理由 |
|---|---|---|---|
| R01 | 名称含「片区」但是景区/园区 | **排除** | E04 |
| R02 | 「示范带」横跨三镇，有指挥部和分村名单 | **纳入 T03** | 机制实体化 |
| R03 | 「示范带」仅是宣传口号，仅有照片墙 | **排除** | E03 |
| R04 | 乡镇内部「乡村振兴办公室」 | **排除** | 是机构不是片区 |
| R05 | 「多村联建党总支」推动产业但不提「片区」 | **纳入 T02** | 机制同构，名称非门槛 |
| R06 | 片区已更名/撤销 | **纳入**，`status=已撤销/已更名`，写 event | 保留生命周期 |
| R07 | 同名片区分属两县 | **分别纳入** | 以 region_code 区分 |
| R08 | 仅有村级「片区」网格（网格化管理） | **排除** | 非发展/振兴单元 |
| R09 | 跨县片区，但每县有独立执行单元 | **各县单元分别纳入**；市级名称记 parent | 保持县级以下粒度 |
| R10 | 片区覆盖跨出该县进入邻县 | **两县各建记录 + 同 parent_area_key** | 可追溯同一跨县工程 |

## 6.5 范围裁定（2025-06）

- **时间**：重点 2022 及以后。2022 年前仅当片区延续至今、或文件明确转入乡村振兴/和美乡村框架
- **地域**：大陆 31 省级单位。港澳台不纳入（P01 关闭）
- **试点**：江苏、浙江、山东先行，字段与覆盖粒度按「乡镇/村名单」能细则细

## 7. 粒度与唯一性

- **入库粒度**：一个「设立行为产生的片区单元」= 一行 `area`
- **唯一键**：`province_code + county_code + name_norm`（名称规范化后）
- **name_norm**：去省/市/县前缀、全半角统一、去「的」「了」等轻声后缀；保留专名

## 8. 时间

| 字段规则 | 说明 |
|---|---|
| `founded_ymd` | 设立/挂牌/印发日期 |
| `founded_precision` | `day` / `month` / `year` / `unknown` |
| 仅知年份 | `founded_ymd=YYYY-01-01` + `precision=year`（导出时只显示年） |
| 无日期 | `founded_ymd` 空 + `precision=unknown`，靠 source 日期兜底 |
