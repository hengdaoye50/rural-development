# 01 · 概念界定

> 版本：v0.1 草案｜权威约束见 `../CLAUDE.md`｜未裁定案例写入文末「待裁定」

## 1. 核心术语

| 术语 | 本项目含义 |
|---|---|
| **片区** | 在县/区（含县级市、旗、特区）**以下**，为推进乡村振兴而**实体化设立**的连片治理或发展单元 |
| **实体化设立** | 有发文、挂牌、成立组织（联合党委/党工委/指挥部/专班）、或列入市县正式实施方案的清单 |
| **覆盖范围** | 片区明确或可合理推定的乡镇/村名单；不可推定则只填所属县 |
| **来源** | 可打开或已存档的官方/权威文本，含 URL、标题、发布者、日期、原文摘录 |

## 2. 纳入标准（四条同时满足）

1. **层级**：设立主体或覆盖空间在**县/区以下**  
   - ✔ 跨村联片、多村联合、乡镇级组团、村企片区、一乡镇内多村  
   - ✘ 全县域「示范县」、市域「示范带」（无县域以下实体单元）
2. **目的**：文本明确服务乡村振兴（产业/人才/文化/生态/组织）或和美/美丽乡村建设
3. **制度**：存在设立动作（§核心术语「实体化设立」）
4. **证据**：≥1 条符合 §5 的来源

## 3. 排除标准（满足任一即排除）

| 编号 | 排除情形 | 示例 |
|---|---|---|
| E01 | 纯行政区划单位 | 某镇、某街道、某行政村 |
| E02 | 县级及以上创建活动 | 乡村振兴示范县、农业现代化示范县 |
| E03 | 仅有规划口号，无设立动作 | 「要打造 XX 片区」但无发文/挂牌/组织 |
| E04 | 纯产业园区/景区/房地产，无乡村振兴任务 | XX 工业园、XX 风景区 |
| E05 | 临时项目部、活动周、一次性观摩点 | 赛事分会场 |
| E06 | 无任何官方/权威旁证的自媒体爆料 | 营销号截屏 |
| E07 | 省级及以上片区（跨市连片）无县域以下执行单元 | 某省「乡村振兴示范带」横跨三市且无县级以下片区 |

**E07 / 象征性命名例外**：满足「公开命名 + 振兴语义」但**无实体设立动作**的示范带/圈/廊/片，**不入 `area`，改入 `belt` 表**（见数据字典 §10）。有指挥部/联合党委/分村名单者仍入 `area` T03。

## 7. 粒度与唯一性

- **入库粒度**：一个「设立行为产生的片区单元」= 一行 `area`
- **唯一键**：`province_code + county_code + name_norm`（名称规范化后）
- **name_norm**：去省/市/县前缀、全半角统一、去「的」「了」等轻声后缀；保留专名

## 10. 统计口径卡（2066-11 定稿）

前面各节管「什么能入库」，本节管**入库之后哪些能进分母**。两者必须分开：
库里可以放宽（有线索即留档），统计必须收紧（可比才算数）。

### 10.1 四界一快照

| 边界 | 取值 | 说明 |
|---|---|---|
| **成立时间窗** | `2022-01-01` ~ `2066-12-31` | 2022 前成立者，只有满足 10.3 的「延续至今」判据才进主统计 |
| **数据快照日** | 建库日（`build_meta.built_at`） | 与成立时间**分开记**。任何对外数字必须同时给出快照日，否则无法复现 |
| **空间界** | 大陆 31 省级单位，主体在县/区以下 | 同 §6.5，不重复 |
| **类型界** | 按**有无官方设立/命名文件**划分，不看命名形态 | 见 10.2 |

### 10.2 类型界：`area` 与 `belt` 的真正分界

判据是**有没有官方设立动作**，不看命名形态（叫「示范带」不影响它进 `area`）：

- **有官方设立动作** → `area`，哪怕名字叫「示范带」「廊带」
- **只有公开命名与振兴语义、无设立动作** → `belt`，哪怕名字叫「片区」

**「设立动作」的两种形态都要认**（2026-11 裁定，理由见下）：

| `setup_kind` | 形态 | 例 |
|---|---|---|
| `roster` | 名单／批复／公布／认定类文件逐条列出 | 辽宁省乡村振兴示范带创建名单（辽农领办〔2023〕13号） |
| `deployment` | 无单独发文，**政府工作报告、专项规划的点名部署** | 上犹县政府工作报告「打造 N 条四融一共示范带」 |

不放宽会把县域最普遍的设立方式判成不存在：中国县级片区大量就是靠年度工作部署确立的，
从没单独发过文。只认 `roster` 等于系统性地筛掉多数县城实践，而它们恰恰是多数。
故 2026-11 起 `deployment` 也算设立动作，但**两者必须分列记录**，报告里能拆开看。

现行做法真正的偏差是**按「该省是否发布名单」分流**（有名单的省进 area、没有的进 belt），
而不是按对象性质。审计结果见 `reports/qa/type-boundary-audit.md`：29 条 `area→belt` 候选中
22 条属 `deployment`（放宽后合法留 `area`），7 条只有媒体命名或零依据（应转 `belt`）；
`belt→area` 5 条里 2 条证据够硬。**在清单逐条裁定前，不得把两张表的数字相加当总量。**

### 10.3 「延续至今」的操作化判据

旧版只说「此前记录仅当延续至今」，但库里没有这个字段，规则无法执行。
2026-11 起用可查证代理判据：**成立时间在 2022 年前，但在 `2023-01-01` 之后仍有
`primary`/`support` 政策（按 `published_ymd`/`issued_ymd`）或 `event`（按 `ymd`）** →
判为延续至今。两者都无 → 判为口径外。

## 11. 双层统计口径（2066-11 定稿）

同一个库要服务两种问题，用一个数字回答不了两种问题，所以分两层，各有自己的准入与用途。
**两层不共用分母，任何跨层比较都无效。**

| | **M 宏观层**（有多少个） | **P 政策层**（政策怎么推） |
|---|---|---|
| 回答的问题 | 各省有多少个片区化单元、分布在哪 | 该省的片区化由什么文件、以什么方式推动 |
| 计量单位 | **命名单元**（`area` 实体片区 + `belt` 象征单元，去重） | 有设立依据的实体片区（`area`） |
| 放宽的是 | **证据强度**：有一条线索即收，含媒体来源、时间不详 | 不放宽——`primary`/`support` + 时间窗 + `setup_kind` 分列 |
| **不放宽的是** | **对象类型**：仍排除 §3 全部情形 | 同 |
| 当前数量 | **1608**（area 1378 + belt 230 − 跨表重名 0） | **556**（`area_caliber.in_main_stat`） |
| 输出 | `reports/宏观层-分省数量.md` | `reports/qa/health-latest.md` 口径分层段 |

### 11.1 关键区分：宽的是证据，不是对象

宏观层「尽可能宽」**只宽在证据强度**——媒体稿、无政策依据、成立时间不详的命名单元都收。
它**不宽在对象类型**：§3 的排除项一条不动，

- 示范县 / 示范镇 / 示范村 → 不收（那是行政层级创建）
- 纯产业园区、纯景区、无乡村振兴任务表述 → 不收
- 城市控规分区（「一河一园五片区」这类）→ 不收

若把对象类型也放宽，宏观层的数字就不再是「片区化单元」，而会变成「所有带片区二字的词」，
拿去做省际比较没有意义。

### 11.2 M 层去重与并表规则

- `area` 与 `belt` 同省、`name_norm` 相同 → 视作同一单元，**保留 `area` 那条**（当前 18 条，湖北 17）
- 排除 `record_state='superseded'`；`status='待核'` **保留**（这正是 M 层要收的）
- `belt` 与 `area` 不同质：M 层报告必须**分列给出**，合计仅作规模参考

### 11.3 M 层能回答什么、不能回答什么

**能**：各省命名单元的数量与量级、分布广度（涉及多少个县）、命名形态偏好（片区/带/廊/圈）、
量级排序与异常值（浙江 390、山东 202 vs 青海 3、宁夏 5、新疆 5）。

**不能**：不能当「各省片区化发展水平」的指标，也不能与其他省份的官方自述数字直接对账。
原因：M 层的完整度由采集覆盖决定，不是由现实决定——青海 3 个不代表青海只有 3 个，
只代表我们只采到 3 个。M 层数字**必须与「县覆盖率」一起报**，单独出现即为误导。

### 11.4 P 层沿用 §10

政策层就是 §10 的口径卡，不再重复。要点：`primary`/`support` 才算依据、时间窗 2022–2066、
`setup_kind` 名单型与部署型分列、D 组由视图排除。

## 13. 新增排除项：美丽宜居村庄「集中连片」（2026-11-21 用户裁定）

「集中连片」指若干村庄在空间上连片，属**村庄环境整治的连片推进**，**不是片区化推进乡村振兴的片区单元**（无跨村治理机制、无片区命名/运营主体）。

- 已删：长沙市 2021 年度美丽宜居村庄「集中连片」认定 113 条（原 D 组）
- 判据：标题含「集中连片」且对象为村庄连片 → 不收；若同时有「片区」命名与运营机制，另行判断
- 工具：`scripts/drop_area_batch.py --policy <政策号> --reason "..."`（raw 移 archive，不删）
