# 01 · 概念界定

> 版本：v0.1 草案｜权威约束见 `../CLAUDE.md`｜未裁定案例写入文末「待裁定」

## 1. 核心术语

| 术语 | 本项目含义 |
|---|---|
| **片区** | 在县/区（含县级市、旗、特区）**以下**，为推进乡村振兴而**实体化设立**的连片治理或发展单元 |
| **实体化设立** | 有发文、挂牌、成立组织（联合党委/党工委/指挥部/专班）、或列入市县正式实施方案的清单 |
| **覆盖范围** | 片区明确或可合理推定的乡镇/村名单；不可推定则只填所属县 |
| **来源** | 可打开或已存档的官方/权威文本，含 URL、标题、发布者、日期、原文摘录 |

## 2. 纳入标准（四条同时满足）

1. **层级**：设立主体或覆盖空间在**县/区以下**  
   - ✔ 跨村联片、多村联合、乡镇级组团、村企片区、一乡镇内多村  
   - ✘ 全县域「示范县」、市域「示范带」（无县域以下实体单元）
2. **目的**：文本明确服务乡村振兴（产业/人才/文化/生态/组织）或和美/美丽乡村建设
3. **制度**：存在设立动作（§核心术语「实体化设立」）
4. **证据**：≥1 条符合 §5 的来源

## 3. 排除标准（满足任一即排除）

| 编号 | 排除情形 | 示例 |
|---|---|---|
| E01 | 纯行政区划单位 | 某镇、某街道、某行政村 |
| E02 | 县级及以上创建活动 | 乡村振兴示范县、农业现代化示范县 |
| E03 | 仅有规划口号，无设立动作 | 「要打造 XX 片区」但无发文/挂牌/组织 |
| E04 | 纯产业园区/景区/房地产，无乡村振兴任务 | XX 工业园、XX 风景区 |
| E05 | 临时项目部、活动周、一次性观摩点 | 赛事分会场 |
| E06 | 无任何官方/权威旁证的自媒体爆料 | 营销号截屏 |
| E07 | 省级及以上片区（跨市连片）无县域以下执行单元 | 某省「乡村振兴示范带」横跨三市且无县级以下片区 |

**E07 / 象征性命名例外**：满足「公开命名 + 振兴语义」但**无实体设立动作**的示范带/圈/廊/片，**不入 `area`，改入 `belt` 表**（见数据字典 §10）。有指挥部/联合党委/分村名单者仍入 `area` T03。

## 4. 类型学 v0.1

入库时 `type_code` 必须属于下表；新类型先改本表再入库。

| code | 名称 | 判定要点 | 优先认 |
|---|---|---|---|
| T01 | 示范片区 | 名称或文件直接称「乡村振兴示范片区」「和美乡村示范片区」等 | 名称含「示范片区」 |
| T02 | 片区联合党委 | 有片区级党组织/党工委/党建共同体实体 | 组织设立文件 |
| T03 | 示范带/廊/圈 | 带状/环状连片 + 有片区化推进机制（指挥部/规划/名单） | 机制证据 > 名称 |
| T04 | 产业片区 | 现代农业/特色产业连片，带乡村振兴任务书 | 任务书/实施方案 |
| T05 | 农文旅片区 | 乡村旅游重点村连片、休闲农业集聚 | 文旅+农业双部门文件优先 |
| T06 | 帮扶协作片区 | 重点帮扶、易地搬迁后续、东西部协作县域子片区 | 帮扶协作方案 |
| T07 | 城乡融合片区 | 城郊连片、城乡融合试验区的县以下单元 | 试验区子单元名单 |
| T08 | 改革试验片区 | 宅基地、集体经营性产权等改革的连片试点 | 改革方案清单 |

**并列**：一单元可主归一类，多标签记入 `tags`（数据字典），不造复合 code。

## 5. 证据标准

| cred | 级别 | 说明 | 能否单独入库 |
|---|---|---|---|
| A | 官方原文 | 政府网、部委、党建网，含文号或规范标题 | 能 |
| B | 官方报道 | 官方媒体/部门公众号，有发布日期 | 能 |
| C | 权威媒体 | 人民日报、新华社、省级党报 | 能，建议补 A/B |
| D | 学术/第三方调研 | 期刊、智库报告 | 否，须与 A/B/C 并用 |
| E | 线索 | 会议纪要、口头、未存档页面 | 否，只进 `status=待核` |

## 6.5 范围裁定（2025-06）

- **时间**：重点 2022 及以后。2022 年前仅当片区延续至今、或文件明确转入乡村振兴/和美乡村框架
- **地域**：大陆 31 省级单位。港澳台不纳入（P01 关闭）
- **试点**：江苏、浙江、山东先行，字段与覆盖粒度按「乡镇/村名单」能细则细

## 7. 粒度与唯一性

- **入库粒度**：一个「设立行为产生的片区单元」= 一行 `area`
- **唯一键**：`province_code + county_code + name_norm`（名称规范化后）
- **name_norm**：去省/市/县前缀、全半角统一、去「的」「了」等轻声后缀；保留专名

## 8. 时间

| 字段规则 | 说明 |
|---|---|
| `founded_ymd` | 设立/挂牌/印发日期 |
| `founded_precision` | `day` / `month` / `year` / `unknown` |
| 仅知年份 | `founded_ymd=YYYY-01-01` + `precision=year`（导出时只显示年） |
| 无日期 | `founded_ymd` 空 + `precision=unknown`，靠 source 日期兜底 |

## 10. 统计口径卡（2026-11 定稿）

前面各节管「什么能入库」，本节管**入库之后哪些能进分母**。两者必须分开：
库里可以放宽（有线索即留档），统计必须收紧（可比才算数）。

### 10.1 四界一快照

| 边界 | 取值 | 说明 |
|---|---|---|
| **成立时间窗** | `2022-01-01` ~ `2026-12-31` | 2022 前成立者，只有满足 10.3 的「延续至今」判据才进主统计 |
| **数据快照日** | 建库日（`build_meta.built_at`） | 与成立时间**分开记**。任何对外数字必须同时给出快照日，否则无法复现 |
| **空间界** | 大陆 31 省级单位，主体在县/区以下 | 同 §6.5，不重复 |
| **类型界** | 按**有无官方设立/命名文件**划分，不看命名形态 | 见 10.2 |

### 10.2 类型界：`area` 与 `belt` 的真正分界

判据是**有没有官方设立动作**，不看命名形态（叫「示范带」不影响它进 `area`）：

- **有官方设立动作** → `area`，哪怕名字叫「示范带」「廊带」
- **只有公开命名与振兴语义、无设立动作** → `belt`，哪怕名字叫「片区」

**「设立动作」的两种形态都要认**（2026-11 裁定，理由见下）：

| `setup_kind` | 形态 | 例 |
|---|---|---|
| `roster` | 名单／批复／公布／认定类文件逐条列出 | 辽宁省乡村振兴示范带创建名单（辽农领办〔2023〕13号） |
| `deployment` | 无单独发文，**政府工作报告、专项规划的点名部署** | 上犹县政府工作报告「打造 N 条四融一共示范带」 |

不放宽会把县域最普遍的设立方式判成不存在：中国县级片区大量就是靠年度工作部署确立的，
从没单独发过文。只认 `roster` 等于系统性地筛掉多数县城实践，而它们恰恰是多数。
故 2026-11 起 `deployment` 也算设立动作，但**两者必须分列记录**，报告里能拆开看。

现行做法真正的偏差是**按「该省是否发布名单」分流**（有名单的省进 area、没有的进 belt），
而不是按对象性质。审计结果见 `reports/qa/type-boundary-audit.md`：29 条 `area→belt` 候选中
22 条属 `deployment`（放宽后合法留 `area`），7 条只有媒体命名或零依据（应转 `belt`）；
`belt→area` 5 条里 2 条证据够硬。**在清单逐条裁定前，不得把两张表的数字相加当总量。**

### 10.3 「延续至今」的操作化判据

旧版只说「此前记录仅当延续至今」，但库里没有这个字段，规则无法执行。
2026-11 起用可查证代理判据：**成立时间在 2022 年前，但在 `2023-01-01` 之后仍有
`primary`/`support` 政策（按 `published_ymd`/`issued_ymd`）或 `event`（按 `ymd`）** →
判为延续至今。两者都无 → 判为口径外。

### 10.4 四组分层（`area_caliber` 视图）

| 组 | 定义 | 数量（快照 2026-11） |
|---|---|---|
| **A** | 成立时间在窗内 + 有 `primary`/`support` 依据 | 434 |
| **B** | 2022 前成立 + 满足 10.3 + 有依据 | 12 |
| **C** | 时间不详（`founded_precision=unknown`）+ 有依据 | 172 |
| **D** | 2022 前成立 + 不满足 10.3（**口径外**，优先于其他组） | 18（其中 5 条有依据、13 条无依据） |
| **E** | 无 `primary`/`support` 依据且未出口径 | 218（其中窗内 147、延续至今 15、时间不详 56） |

五组互斥，合起来 = 854。`area_caliber.caliber_group` 即按此优先级生成：
**D 优先于 E**——出了时间口径的记录，无论有没有依据都不进统计。

### 10.5 计数规则（对外一律按此报）

| 口径名 | 组成 | 数量 | 能回答什么 |
|---|---|---|---|
| **主统计** | A + B | **446** | 时间与依据都成立，可做年份序列、可跨省比较 |
| **宽统计** | A + B + C | **618** | 有依据且未失效；因含时间不详，**不得进年份分布** |
| 全量库 | 全部 active 且非待核 | 854 | 只用于说明采集规模，**不得当结论基数** |
| 待核 / 无依据 | E 等 | 228 / 231 | 单列，不进任何分子 |

**旧数字（854、827、96.8%、80.8%）一律标注口径与快照日**，不得与新口径混排。

### 10.6 不可变约定

- D 组**不删记录、不改 `status`**，由视图排除。口径变只改视图与本文档，不回溯改数据。
- 口径调整必须同时改本节与 `scripts/build_db.py` 的视图定义，并跑 `validate_db.py`。
- 报「片区数量」时必须三选一明确说：主统计 446 / 宽统计 618 / 全量库 854。
