# 00 · 整体规划

> 版本：v0.1（规划期）｜ 对应约束：`../CLAUDE.md`

## 一、问题定义

**要回答的问题**：在全国各省、自治区、直辖市下辖的县/区（含县级市、旗）**以下**，哪些地方成立了以「片区」为单元的组织机制或空间单元，用来推进乡村振兴？它们何时设立、以何种方式设立、覆盖多大范围、依据什么政策、成效如何？

**不是**要回答的问题（防跑偏）：

- 不是全国乡村振兴政策的全文汇编
- 不是示范县/示范镇/示范村名录（那些是行政层级创建，不是片区）
- 不是乡村行政区划数据库（乡镇街道不自动等于片区）

## 二、交付物

| 交付物 | 形态 | 用途 |
|---|---|---|
| 片区实体库 | SQLite + clean CSV | 逐条片区记录 |

## 三、核心概念（操作性定义摘要）

完整标准见 `01-概念界定.md`。摘要：

**纳入**同时满足：

1. **空间层级**：主体在县/区**以下**（跨村联片、乡镇级组团、多村联合、村企片区等）
2. **设立目的**：明确服务于乡村振兴总要求（产业、人才、文化、生态、组织任一或综合）
3. **制度存在**：有可查证的正式设立行为（发文、挂牌、成立联合党委/专班/指挥部、列入市县实施方案）
4. **证据完备**：至少一条官方或权威媒体来源

**排除**：

- 单纯的乡镇/街道/行政村
- 县级及以上「示范县/创建县」
- 仅有口号、无设立动作的「规划设想」
- 纯产业园区、纯景区，且无乡村振兴任务表述

**类型学 v0.1**（可增补，须写入 01 后再入库）：

| 代码 | 类型 | 典型形态 |
|---|---|---|
| T01 | 示范片区 | 乡村振兴示范片区 / 和美乡村示范片区 |
| T02 | 片区联合党委 | 跨村联建、片区党工委、党建共同体 |
| T03 | 示范带/廊/圈 | 若与片区机制同构，经裁定后纳入 |
| T04 | 产业片区 | 现代农业/特色产业连片，带乡村振兴任务书 |
| T05 | 农文旅片区 | 乡村旅游重点村片区、休闲农业片区 |
| T06 | 帮扶协作片区 | 重点帮扶、易地搬迁后续扶持、东西部协作片区 |
| T07 | 城乡融合片区 | 城郊型片区、城乡融合试验区（县以下单元） |
| T08 | 改革试验片区 | 农村改革试点（宅基地、集体经营性建设用地等）的县域子单元 |

## 四、数据模型（逻辑）

```
region(行政区划) 1---* area_region_map *---1 area(片区) *---1 area_type
                         |
                         1---* source(来源) 
                         1---* policy(政策文件)
                         1---* event(设立/评估/更名等事件)
```

关键实体与关键字段（详见数据字典）：

- **area**：`area_id`, `name`, `type_code`, `province_code`, `founded_ymd`, `founded_precision`, `status`, `scale_villages`, `lead_org`, `summary`
- **region**：`region_code`（GB/T 2260）, `name`, `level`（province/city/county/town/village）
- **source**：`source_id`, `area_id`, `url`, `title`, `publisher`, `published_ymd`, `excerpt`, `fetched_at`, `credibility`
- **policy**：`policy_id`, `title`, `doc_no`, `issuer`, `issued_ymd`, `url`
- **event**：`event_id`, `area_id`, `event_type`, `ymd`, `note`

## 五、采集策略

### 5.1 来源优先级

1. 中央部委（农业农村部等）文件与案例库
2. 省级乡村振兴局/农业农村厅方案与名录
3. 市县政府网、党建网、乡村振兴局动态
4. 权威媒体（人民日报、新华社、地方党报）
5. 学术期刊与调研报告（仅作旁证，不单独作为唯一来源）

### 5.2 检索矩阵（关键词 × 范围）

| 维度 | 关键词示例 |
|---|---|
| 机制 | 片区、示范片区、片区联合党委、连片、组团、示范带、示范圈 |
| 任务 | 乡村振兴、和美乡村、美丽乡村、产业振兴、农文旅、共同富裕 |
| 层级 | 跨村、多村、乡镇、联合、片区指挥部 |
| 命名 | 「XX县XX片区」、「XX镇XX片区」、「XX乡村振兴示范带」 |

范围：`{省/市/县} × {关键词}`，县名单来自 `docs/04-行政区划代码表.md`。

### 5.3 采集流程（单批）

1. 立计划（范围、关键词、预计条数）
2. 检索 → 打开页面 → 保存原文到 `data/raw/.../原文.md` + `meta.json`
3. 抽取到 `data/stage/{批次}.csv`（宽松字段）
4. 对照概念界定裁定纳入/排除/待核
5. 规范化写入 `data/clean/{表}.csv`
6. `build_db.py` 重建库 → `validate_db.py` 出 QA 报告

### 5.4 质检规则

| 规则 | 处理 |
|---|---|
| 无 URL/摘录 | 不入 clean |
| 名称疑似但无设立证据 | `status=待核`，保留 |
| 跨省同名片区 | 以 `region_code` 区分，禁止合并 |
| 时间只知年月 | `founded_precision=month`，日不填 |
| 与既有记录冲突 | 写入 `reports/qa/conflicts-*.csv`，人工裁定 |

## 六、技术方案

**刻意保持轻量**：数据量预估 1e3–1e4 条片区记录、1e4–1e5 条来源，SQLite 足够；不引入 ORM、不建 Web 服务（第二阶段再议）。

| 阶段 | 栈 | 产出 |
|---|---|---|
| P0 现在 | 文档 + 目录 + 数据字典 | 规范就绪 |
| P1 | Python + pandas + SQLite | 试点省入库 |
| P2 | 同上 + 报告脚本 | 分省铺开 |
| P3 | 可选：DuckDB/GeoPandas、静态站点 | 查询与地图 |

依赖（新增须写入 CLAUDE.md）：`pandas`, `openpyxl`, `requests`, `beautifulsoup4`, `ruff`。

## 八、风险与对策

| 风险 | 影响 | 对策 |
|---|---|---|
| 「片区」口径不一 | 结果不可比 | 操作性定义 + 待裁定队列 + 决策日志 |
| 基层信息公开不全 | 漏采 | 负面清单（查无 ≠ 不存在）；补采批次 |
| 片区更名/撤销 | 历史失真 | event 表记录生命周期，不删旧名 |
| 重复/同名 | 统计失真 | region_code + 唯一约束 + 冲突报告 |
| 权力和口径变化（机构改革） | 来源失效 | 保存快照摘录，不只存 URL |
| 采集工作量巨大 | 无法完成 | 分省批次、优先高密度省、允许抽样估计 |

## 十一、分表策略（area vs belt）

| | `area` 实体片区 | `belt` 象征性单元 |
|---|---|---|
| 标准 | 01 四条纳入标准 | 有公开命名（示范带/圈/廊/片等）+ 振兴语义，**无**实体设立动作 |
| 用途 | 主结论、机制分析 | 传播与命名分析、趋势、对照组 |
| 质量 | 来源 A/B/C 优先 | 允许 B/C/D；可更薄字段 |
| 统计 | 默认进报告主统计 | 默认单列，不与 area 合并计数 |
