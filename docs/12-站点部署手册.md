# 从零部署教程：GitHub Actions → Cloudflare Pages → ruraldevelopment.jinhuazhang.top

> 适用前提：仓库 `hengdaoye50/rural-development` 已存在、`jinhuazhang.top` 已在 Cloudflare 托管。
> 仓库里已有：`package.json`（`npm run build` = `node scripts/build-site.mjs`）、`wrangler.toml`、
> `.github/workflows/deploy.yml`。整套流程 15 分钟，只有 5 个手动步骤。

---

## 第 0 步：先理解要建什么

```
本地 web/  ──build──▶  dist/  ──GitHub Actions──▶  Cloudflare Pages 项目 ──▶  自定义域名
```

- Cloudflare 侧只需要**一个 Pages 项目**（名字固定 `rural-development`）；
- 真正把文件传上去的是 GitHub Actions 里的 `wrangler pages deploy`；
- 因此**不要在 Cloudflare 页面里选 "Continue with GitHub"**——那会让 Cloudflare 自己构建一份，
  与 Actions 重复。你现在看到的 "Create an app" 页面直接关掉即可。

---

## 第 1 步：创建 Pages 项目（命令行，最省事）

打开 PowerShell：

```powershell
cd "D:\CODEX\全国乡村片区化数据库"
npx wrangler@4 login
```

浏览器会弹出 Cloudflare 授权页 → 选你的账号 → **Allow**。

```powershell
npx wrangler@4 pages project create rural-development --production-branch=main
```

看到下面这行就成功：

```
✨ Successfully created the 'rural-development' project.
```

> 如果你更喜欢网页：Cloudflare 首页 → **Workers & Pages** → 底部 **Continue to Pages** →
> **Create a project** → **Direct Upload** → 名字填 `rural-development` → 上传任意一个 `index.html` 完成创建。
> 上传内容无所谓，Actions 会覆盖。

---

## 第 2 步：拿 Account ID

```powershell
npx wrangler@4 whoami
```

输出里的 `Account ID`（32 位十六进制）复制下来。

网页也可拿：Cloudflare 首页右侧栏底部 **Account ID**。

---

## 第 3 步：创建 API Token

1. 登录 <https://dash.cloudflare.com/>
2. 右上角头像 → **My Profile**
3. 左侧 **API Tokens** → **Create Token**
4. 拉到最下面 **Create Custom Token** → **Get started**
5. 按下表填：

| 字段 | 填什么 |
|---|---|
| Token name | `rural-development-deploy` |
| Permissions | **Account** → **Cloudflare Pages** → **Edit** |
| Account Resources | **Include** → 你的账号 |
| TTL | 留空（不过期） |

6. **Continue to summary** → **Create Token**
7. 复制 token（**只显示一次**，务必先存到记事本）

---

## 第 4 步：把两个值写进 GitHub Secrets

打开：<https://github.com/hengdaoye50/rural-development/settings/secrets/actions>

点 **New repository secret**，加两条：

| Name（必须完全一致） | Secret |
|---|---|
| `CLOUDFLARE_API_TOKEN` | 第 3 步的 token |
| `CLOUDFLARE_ACCOUNT_ID` | 第 2 步的 Account ID |

> Secrets 是**按仓库隔离**的：创新案例库仓库里那套在这里不能用，必须重新加。

---

## 第 5 步：提交并推送，触发第一次部署

```powershell
cd "D:\CODEX\全国乡村片区化数据库"
git add -A
git commit -m "feat(site): 多页站点 + Cloudflare Pages 部署配置"
git push origin main
```

push 后自动触发 Actions：

<https://github.com/hengdaoye50/rural-development/actions>

打开最新的 **Deploy to Cloudflare Pages**：

- 绿勾 → 部署成功；
- 红叉 → 点进去看哪一步失败，对照文末「常见错误」。

也可以在 Actions 页面点 **Run workflow** 手动触发。

---

## 第 6 步：绑定自定义域名

1. Cloudflare 首页 → **Workers & Pages** → **rural-development**
2. 上方 **Custom domains** 标签 → **Set up a custom domain**
3. 输入 `ruraldevelopment.jinhuazhang.top` → **Continue**
4. 点 **Activate domain**

因为 `jinhuazhang.top` 的 NS 已在 Cloudflare（`nelly.ns.cloudflare.com` / `ken.ns.cloudflare.com`）
且是同一个账号，Cloudflare 会**自动**创建这条 CNAME：

```
ruraldevelopment  CNAME  rural-development.pages.dev  （Proxied）
```

不用你手动去 DNS 加记录。证书 1–5 分钟自动签发。

> 如果你想手动确认：**DNS** → **Records**，应能看到上面这条。
> 若被同名 A 记录占用，先删掉旧的再重试。

## 第 7 步：验收

浏览器打开 <https://ruraldevelopment.jinhuazhang.top>，依次检查：

1. 首页出现地图，省份可点；
2. 导航 6 个页面都能打开（概览/地图/省份/检索/方法与质量/关于）；
3. 「关于」页的下载链接能下到 CSV / GeoJSON；
4. `https://` 有锁，无证书警告；
5. 手机打开正常（375 宽无横向滚动）。

命令行可快速验证：

```powershell
curl.exe -I https://ruraldevelopment.jinhuazhang.top
```

看到 `HTTP/2 200` 即可。

## 日常更新流程

```powershell
# 改完数据或页面后
python scripts/export_web_assets.py      # 重新导出前端数据（可选）
node scripts/build-site.mjs              # 本地构建，先看 dist/
git add -A; git commit -m "data: 更新快照"
git push origin main                     # 自动部署
```

回滚：Cloudflare → Pages → rural-development → **Deployments** → 选历史版本 → **Rollback**。

## 常见错误对照

| 现象 | 原因 | 处理 |
|---|---|---|
| `project not found` | 项目名不是 `rural-development`，或建在了别的账号 | 用 `npx wrangler@4 pages project list` 确认 |
| `Authentication error` / 401 | token 缺 `Pages: Edit`，或 Account ID 错 | 重建 token；用 `whoami` 重新核对 ID |
| `Missing entry-point` | 构建没产出 `dist/` | 本地先跑 `node scripts/build-site.mjs` 看是否成功 |
| Actions 报 secret 不存在 | 名字拼错 / 加到了 fork | 名字必须全大写与上表一致 |
| 域名一直 Pending | 项目在另一个 CF 账号下 | 用域名所在账号重建项目 |
| 打开是 Cloudflare 404 | dist 里没有 index.html | 检查构建步骤日志 `files=` 数量 |
| 页面样式丢失 | 路径写死绝对路径 | 站点内一律用相对路径（已按此实现） |

## 备选方案：不用 Actions，改用 Cloudflare 自带 Git 构建

如果以后不想维护 token，可以改用 Cloudflare 的 Git 集成：

1. **Continue with GitHub** → 选 `rural-development` 仓库
2. Build command：`node scripts/build-site.mjs`
3. Build output directory：`dist`
4. 保存后，每次 push 由 Cloudflare 自己构建
5. **同时删除** `.github/workflows/deploy.yml`，避免两套重复部署

两种方式二选一，不要同时开。
