- **原则**：以国家统计局最新统计用区划代码为准，每年核对一次

- **手工补丁**：若有民政部调整，写 `data/stage/region-patch.csv`，由脚本合并

## 4. 直辖市规则

- `city_code` = 直辖市码（如 310000）
- `county_code` = 市辖区/县码（如 310115）
- 禁止把街道/乡镇写入 `county_code`
