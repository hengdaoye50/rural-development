# 03 · 采集规范

> 版本：v0.1｜遵循 `../CLAUDE.md` 与 `01-概念界定.md`

## 1. 单批采集流程

1. **立计划**：在 `data/stage/batches.csv` 追加一行：批次号、省码、关键词、负责人、日期
2. **检索**：按 §2 矩阵检索；优先政府域名（`.gov.cn`）
3. **保存证据**：对每条候选
   - 建目录 `data/raw/{省码}-{省名}/{YYYYMMDD}-{slug}/`
   - 保存 `原文.md`（标题、发布者、发布日期、正文相关段落）
   - 填 `meta.json`：`url, title, publisher, published_ymd, fetched_at, cred`
4. **抽取**：写入 `data/stage/{批次号}-candidates.csv`（宽松字段，允许空）
5. **裁定**：对照 01 纳入/排除；`排除` 也要写一行 + `exclude_code`（E01–E07）
6. **规范化**：按 02 字典写入 `data/clean/area.csv`、`source.csv` 等
7. **构建与质检**：

```powershell
& $env:MIMO_PYTHON scripts/build_db.py --batch {批次号}
& $env:MIMO_PYTHON scripts/validate_db.py --out reports/qa/{批次号}.md
```

8. **冲突处理**：`validate_db.py` 写出的冲突 CSV 须人工闭环后再入下一阶段

## 2. 检索关键词矩阵

| 组 | 关键词 |
|---|---|
| 机制 | 片区 联合党委 示范片区 连片 推进 组团 片区化 指挥部 党工委 |
| 任务 | 乡村振兴 和美乡村 美丽乡村 产业振兴 五大振兴 农文旅 共同富裕 |
| 组合 | `{县名}+片区+乡村振兴`、`{县名}+示范片区`、`{市名}+片区联合党委`、`{县名}+连片+示范` |
| 文件 | 实施方案、创建名单、挂牌、成立、印发 |

**范围**：`省 × 县 × 关键词`；县列表来自 `04-行政区划代码表.md`。

## 3. 来源与可信度

见 `01-概念界定.md` §5。实操要点：

- A/B 级必须能定位到具体段落；摘录 ≥40 字且含「设立/成立/挂牌」与「振兴/乡村」语义
- 页面可能消失：`local_path` + `hash_sha256` 必填（A/B 级）
- 仅转载无原文链接 → 降为 D 或 E

## 4. 命名与去重

- `name`：来源中最完整通行名
- `name_norm`：删前缀行政区、统一空白与全角、删「（第X批）」括注
- 查重顺序：`name_norm` → `county_code` → `lead_org` → 标题相似
- 同片区多来源：加 `source` 行，不新建 `area`

## 5. 交叉验证

| 检查 | 动作 |
|---|---|
| 县政府 vs 省政府报道名称不一致 | 以发文单位更近者为准，记 event `更名`/`别名` |
| 覆盖村数与名单村数不符 | `scale_villages` 取名单计数；差异写 QA |
| 时间相差 | 取发文/挂牌日；媒体早于发文则取发文 |

## 6. 负面清单制度

查无记录 ≠ 不存在。每省结束后输出：

```
reports/gaps/{省码}-missing-counties.csv
```

列：`county_code, county_name, searched_terms, search_date, note`  
供后续补采，不写「该县无片区」。

## 7. 节奏与配额（建议）

| 阶段 | 节奏 |
|---|---|
| 试点省 | 深度采集，允许 1–2 周 |
| 普通省 | 每省 1 批核心关键词 + 1 批补缺 |
| 高密度省（浙苏鲁川湘等） | 2–3 批 |

## 8. 伦理与合规

- 遵守网站 robots 与服务条款；控制并发与频率
- 不采集个人隐私（村民姓名非公开职务信息）
- 不绕过付费墙/登录墙抓取；需要登录则停止并记录
- 脚本爬虫仅用于公开政务/媒体页，密钥与代理配置进 `.env`
