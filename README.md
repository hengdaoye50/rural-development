# 全国乡村片区化数据库

## 设计原则

1. 证据制：无来源不入库  
2. 操作性定义优先于名称匹配  
3. raw / stage / clean / db 分层，可重建、可追溯  
4. 查无 ≠ 不存在：用缺口清单代替否定结论
